# Cú — bộ tài liệu dự án

Giải nén vào thư mục gốc của repo. Cấu trúc khớp với `CLAUDE.md`.

| File | Dùng cho |
| --- | --- |
| `CLAUDE.md` | Bộ nhớ dự án cho Claude Code: 15 quy tắc cứng, stack, cấu trúc repo, quy ước |
| `docs/SPEC.md` | Đặc tả triển khai đầy đủ, task giai đoạn 0 |
| `docs/CURRICULUM.md` | Hướng dẫn nhập mục lục SGK lớp 5, thuật ngữ, cách giải, cập nhật tiến độ |
| `docs/DESIGN.md` | Bản xuất của tài liệu thiết kế (Claude Doc) — lý do, phân tích được/mất, hội thoại mẫu |
| `data/curriculum/math/grade5.yaml` | Khung mục lục Toán 5, chưa có bài — điền theo `docs/CURRICULUM.md` |
| `data/curriculum/math/beyond-grade5.yaml` | Khung danh sách thuật ngữ lớp trên, chưa có mục |

Khi các file mâu thuẫn: quy tắc cứng trong `CLAUDE.md` thắng, sau đó `docs/SPEC.md`. `docs/DESIGN.md` là tài liệu giải thích, không phải đặc tả.
